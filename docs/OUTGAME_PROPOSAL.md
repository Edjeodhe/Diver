# 아웃게임(경영) 콘텐츠 제안서 — 검토용

> 상태: **제안 / 미구현**. 아래 안 중 하나(또는 조합)를 골라 주시면 P1에서 구현합니다.
> 전제: 다이브에서 얻은 수확물(물고기 16종, 채집물 7종)을 재료로 쓰고, 경영 수익이 장비 강화 자금이 되는 순환 구조.
> 지금은 이 자리를 "귀환 시 자동 정산"이 임시로 대신하고 있습니다.

## 공통 설계 원칙
- **인게임과 맞물려야 한다**: 경영 쪽 수요(주문, 의뢰)가 "다음 다이브에서 무엇을 노릴지"를 정해 줘야 한다.
- **짧은 세션**: 다이브 1회 = 하루. 경영 파트는 3–5분 안에 끝나야 한다.
- 미니게임은 제외한다(요청 사항). 결정과 운영 중심으로 설계한다.

---

## 안 A. 해녀 포장마차 (야간 식당 경영) ★추천
섬 포구의 작은 포장마차. 낮에는 물질하고 밤에는 장사한다.

- **메뉴 편성**: 창고 재료로 그날 팔 메뉴를 3–6개 고른다(성게 미역국, 전복죽, 물회, 참돔 구이 …). 메뉴마다 재료 레시피가 있다.
- **영업 시뮬레이션**: 손님 유형(관광객, 어부, 미식가)과 선호도에 따라 자동으로 주문이 들어온다. 플레이어는 결정만 한다. 재료가 떨어진 메뉴의 품절 여부, 가격 조정, 직원 배치 같은 것들이다.
- **평판과 등급**: 별점이 쌓이면 좌석과 메뉴 슬롯이 늘고 특별 손님이 온다.
- **레시피 연구**: 처음 잡은 생물로 신메뉴를 해금한다. 도감과 연동된다.
- **인게임 연결**: "내일 단체 손님이 대왕바리 요리를 원한다" 같은 예약 주문이 다음 다이브의 목표가 된다.
- 장점: 장르 기대치에 맞고, 다이브 동기 부여가 가장 강하다. 해녀 테마와도 잘 맞는다.
- 리스크: 손님 AI와 UI 분량이 가장 크고, 다른 다이빙 + 식당 게임과 겹친다는 인상을 받을 수 있다. 그래서 차별화(포장마차 규모, 결정 중심, 해녀 음식)가 중요하다.

## 안 B. 섬 수산 시장 & 경매
- 매일 아침 경매장에 수확물을 출품한다. 시세는 수요, 계절, 날씨, 다른 어선의 물량에 따라 변한다.
- **시세 정보**: 게시판에 "오늘 방어 시세 ↑"가 뜨면 다이브 목표가 정해진다.
- **보관 결정**: 냉동 창고 용량 안에서 지금 팔지, 시세가 오를 때까지 들고 있을지 정한다.
- **도매 계약**: 일정 기간 특정 어종을 납품하면 보너스를 받는다.
- 장점: 구현 비용이 가장 낮고 수치 중심이라 밸런싱이 쉽다.
- 리스크: 감정적 몰입이 약하다. 단독으로 쓰기보다 A 또는 C의 보조 시스템으로 적합하다.

## 안 C. 해양 생물 아쿠아리움 운영
- 그물총으로 **산 채로 포획**한 생물을 수조에 전시한다(현재 그물 포획 시스템을 확장).
- 수조 배치, 수온과 수심대 조건, 생물 간 궁합(포식 관계)을 관리한다.
- 입장객 수익과 연구 의뢰("심연 생물 3종 전시")가 있고, 전시 등급이 오르면 박물관 기증 보상을 받는다.
- 장점: 도감과 수집 욕구를 가장 크게 자극하고, 정예와 희귀 개체의 가치가 커진다.
- 리스크: 수조 연출 아트 비용이 크다. "잡아서 먹는" 경제와 따로 분리해 설계해야 한다.

## 안 D. 해녀 공동체 & 마을 재건 (메타 성장)
- 수익을 들여 포구 시설(잠수복 공방, 해녀 탈의장 "불턱", 등대, 냉동 창고)을 재건한다.
- 시설마다 영구 버프를 준다. 예를 들어 불턱은 출발 산소 +10%, 등대는 탁한 물 페널티를 줄여 준다.
- 다른 해녀 NPC를 영입해 대리 물질(자동 수익)을 보내거나 함께 출항하는 동료로 쓴다.
- 장점: 로그라이크 메타 성장과 가장 자연스럽게 맞물리고, 스토리를 담는 그릇이 된다.
- 리스크: 단독으로는 경영의 재미가 약해서 A/B/C와 조합해야 한다.

## 추천 조합
**A(해녀 포장마차)를 메인으로, B의 "시세/예약 주문"을 수요 생성기로 흡수하고, D는 장기 메타로 둔다.**

| 단계 | 내용 |
|---|---|
| P1 | 포장마차 최소 기능: 메뉴 편성 → 자동 영업 → 정산 → 평판 |
| P1.5 | 예약 주문(다이브 목표 연동), 레시피 연구 |
| P2 | 마을 재건(D) 메타 성장, 직원(해녀 NPC) |
| 보류 | 아쿠아리움(C)은 콘텐츠 확장 DLC 후보 |

## 결정이 필요한 것
1. 메인 아웃게임: A / B / C / D 중 무엇으로 할지
2. 수확물 처리 방식: 지금처럼 귀환 시 자동 정산을 유지할지, 창고 보관 후 경영 파트에서 쓸지 (A·B·C 모두 창고 방식이 필요)
3. 경영 파트의 조작 깊이: 결정만 하는 방식(추천)인지, 실시간 운영인지 (미니게임 제외 원칙 때문에 결정 방식 권장)
